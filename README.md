# FastFourierProject

A project for COP4531 - Algorithm Design and Analysis at Florida Polytechnic University.

-This project implements the Fourier transform in both brute force and radix-2 DIT Cooley-Tukey approaches.

Suggested compilation command from main directory:
    g++ main.cpp BruteForceDFT/BruteFourier.cpp CooleyTukeyFFT/CooleyTukeyFDFT.cpp Resources/Signal.cpp
